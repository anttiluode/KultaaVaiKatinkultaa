# Kultaa vai katinkultaa? — Gold or fool's gold?

This repository tests signed prediction-error neurons and self-writing, self-erasing memory from the unchanged GeometricNeuronV27 equations. The lineage is [GeometricNeuronV27](https://github.com/anttiluode/GeometricNeuronV27) → [GN-XOR](https://github.com/anttiluode/GN-XOR) → this experiment.

**Status (12 November 2026):** Initial dynamic simulations demonstrated synchronous XOR, AND, signed innovation/omission discrimination, and acquisition and erasure of repeating event slots in a fixed 32-tick ring. The period and wiring are configured by the experimenter; general rule learning has not been demonstrated.

Experiments and reproducibility checks follow. The name explicitly asks whether this is gold or fool's gold: the tests, not enthusiasm, decide.
